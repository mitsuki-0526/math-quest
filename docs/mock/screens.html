提案: 同一主人公の三部作 + どの学年からでも始められる設計

主人公(名前はプレイヤー入力)は3年かけて成長する一本の物語。ただし各学年版は単体で開始でき、前学年のセーブがあれば「レベル・仲間・称号」を引き継いでボーナスをもらえる(なければ「これまでのあらすじ」から標準ステータスで開始)。転入生や2年から使い始めるクラスでも困らない。

学年舞台テーマあらすじ単元との対応(例)
1年
「はじまりの国 プリマ」		東の辺境。村・森・湖・山「数の秩序」を取り戻す世界に「歪み」が広がり、数が嘘をつき始める(橋の長さが −12m、商人の計算が合わない)。村の少年/少女ユウは、知恵フクロウのピタと出会い、各地の「理(ことわり)の碑」を修復する旅に出る。ラストで歪みは自然災害ではなく「誰か」が起こしていると知る。正負の数=符号の森 / 文字と式=名もなき者の平原 / 方程式=未知の洞窟(敵「X」) / 比例反比例=天秤の湖 / 平面図形=円の遺跡 / 空間図形=立体の山 / データ=記録の塔
2年
「王国 セクンダ」		大陸中央。王都・城下・街道「変化と関係」を読み解く王都に召喚されたユウは、騎士見習いのレナ(仲間2)と組む。歪みの黒幕は元・王国大賢者ゼノン。「争いは損得の計算から生まれる。ならば数を世界から消す」が動機。二人の力を合わせる(連立)、変化を予測する(一次関数)、偶然を読む(確率)ことで王都を守り、ゼノンの居城「北の塔」の存在を知る。式の計算=錬金術師の工房 / 連立方程式=双子の門 / 一次関数=時計塔 / 平行と合同=鏡の回廊 / 三角形と四角形=城壁 / 確率=道化師のカジノ / 箱ひげ図=王立記録院
3年
「天空の塔 テルティア」		北の塔。塔は登るほど「根源」に近づく「根源と形」にたどり着く塔を登る最終章。ピタの正体は古代の学者ピュタゴラスの使い魔で、三平方の定理の章で真の力を解放する。最上階でゼノンと対峙。倒すのではなく「理は人を縛るものではなく、分かり合うための言葉」だと証明して救う。エンディングで主人公は新しい「理の書」(=中学数学の全体像)を書き上げる。展開因数分解=分解の間 / 平方根=根の泉 / 二次方程式=二つの答えの扉 / y=ax²=放物線の橋 / 相似=巨人の間 / 円周角=円環の回廊 / 三平方=ピタの真実 / 標本調査=最終試練

共通ルール

  • 1章 = 1単元 = 1エリア。教科書の単元順に並べ、先生がシートで解放。各章のボスはその単元の「象徴」となる敵(符号王ネガ、未知なる影X、双子の門番…)。
  • 雑魚敵 = 問題テンプレート。「マイナススライム(負の数の加減)」のように、敵の種類=出題タイプ。図鑑が単元の一覧表になる。
  • ボス戦のみ図形・グラフ問題(SVG描画)を混ぜて「特別感」を出す。
  • 仲間の役割 = 学習サポート。ピタ=ヒント、レナ=かばう(誤答ダメージ軽減)、3年の仲間=難易度調整…のように、RPGのスキルと学習支援を一致させる。
  • 伏線: 1年の「碑文に刻まれた三角形」→3年で三平方。1年の商人の「損得」の話→2年のゼノンの動機。
