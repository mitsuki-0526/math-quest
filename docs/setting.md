# MathQuest(仮称) 設定資料

- 作成日: 2026-09-20 / 最終更新: 2026-09-20
- ステータス: draft
- 関連文書: [シナリオ設計書](scenario.md)(骨格) / [台本](script/)(本文)

> 名前はすべて **仮名**。台本と実装(`characters.ts`)から一括で差し替える。

この文書は「セリフを書くときに毎回参照するもの」。人物の口調・信念・知っていること/知らないこと、世界のルールを固定し、章をまたいでも矛盾しないようにする。

## 1. 世界のルール

### 1.1 理(ことわり)

- 世界の形を保っている「数・形・関係のきまり」。人々は空気のように使っている(勘定、測量、種まきの量)
- 理は誰かが「言い直す」(正しく述べる)たびに、その土地で強まる。忘れられると弱まる
- **理は人を縛るものではない**(3年で主人公が証明するテーマ)。1年では言葉にせず、ピタの口ぐせ「まちがえたら、言い直せばいい」で体現する

### 1.2 理の碑(ことわりのひ)

- 千年前、「**碑守(ひもり)**」と呼ばれる学者たちが大陸各地に建てた石碑。碑文にその土地の理が刻まれている
- 碑が健全なあいだ、周辺の理は安定する。碑は土地の「まとめ」のような存在
- 各碑の碑文は **短い1〜2文**(例: 符号の碑「負の数どうしの積は正である」)。章のボス後に主人公が碑文を「言い直す」(正しい碑文を選ぶ)ことで修復が完了する
- 碑文の末尾には必ず「**北を見よ**」と刻まれている(碑守たちの本拠=北の塔テルティアを指す。3年の伏線)

### 1.3 歪み(ゆがみ)

- 1年ほど前に北から広がり始めた現象。歪んだ土地では **数が嘘をつく**(看板の長さが負になる、勘定が合わない、水が比例しない)
- 歪みは碑の碑文を **書き換える**(「負×負は負」など)。書き換えられた碑の周りに「**歪みの子**」(魔物)が湧く
- 魔物はそれぞれ **特定の理の誤りの姿**。倒す=その誤りを正しく言い直す。倒しても人は死なない、魔物も「消える」のではなく「元の姿(小動物・石・風)に戻る」
- 歪みの正体: 元大賢者ゼノンが「数のない世界」を作ろうと、北の塔から放ったもの。1年ではこの事実は最終章で「送り主がいる」と分かる段階まで
- **間違えると歪みが強まる、という設定にはしない**。歪みは「理が忘れられた場所」に広がる。間違えること自体は悪ではなく、言い直せば戻る(学習ゲームとしての倫理)

### 1.4 地理

```
        [北] 天空の塔 テルティア(3年)
              |
        王国 セクンダ(2年) — 王都・城下・街道
              |
  [東] はじまりの国 プリマ(1年)
        はじまりの村 → 符号の森 → 名もなき者の平原 → 未知の洞窟 →
        天秤の湖 → 円の遺跡 → 立体の山 → 記録の塔(北端)
```

- プリマは王国の東の辺境。王都の役人はめったに来ない。関所(=教師の解放)は「王国の通行許可」という建前
- 記録の塔はプリマ最北。ここからは王国領で、塔の窓から遠く北の塔が見える

### 1.5 年表

| 時期 | 出来事 |
|---|---|
| 約千年前 | 碑守たちが理の碑を建てる。碑守の一人はフクロウを連れていた(ピタの主人=ピュタゴラス) |
| 約20年前 | 王国と隣国の戦争。ゼノン(当時の王国大賢者)は家族を失う。戦争の原因は領土と収穫の「勘定」だった |
| 約10年前 | ゼノン、「数がなければ人は争わない」と唱えて王都を去る。記録にはそう残る |
| 約1年前 | 北の塔から歪みが広がり始める。王国は騎士団を調査に出す(レナの兄ノアもその一人) |
| 数か月前 | 歪みがプリマに到達 |
| 物語開始 | はじまりの村の橋の看板が「−12m」になる |

## 2. 登場人物(仮名)

### 2.1 ユウ(主人公・プレイヤーが命名)

| 項目 | 内容 |
|---|---|
| 年齢・立場 | 12〜13歳。はじまりの村の子。両親は村で農家(物語に絡まない) |
| 見た目 | **最初に「男の子 / 女の子 / きめない」から選ぶ**(立ち絵が変わるだけ)。セリフ・物語は見た目に依存させない。主人公は**一人称を使わない**書き方にする(セリフは短く、選択肢中心) |
| 性格 | 好奇心が強く、困っている人を放っておけない。数学が得意という設定にはしない(プレイヤーの実力=ユウの実力) |
| 才能 | 理を「言い直す」力。碑守の血筋などの特別な出自は **ない**(誰でもできることを示すため) |
| 口調 | 短い。「行こう」「どういうこと?」「わかった」。敬語は大人に対してだけ軽く |
| 成長 | 1年: 村を守る → 2年: 王都を守る → 3年: 世界と、ゼノン一人を救う |

### 2.2 ピタ(仲間・案内役)

| 項目 | 内容 |
|---|---|
| 姿 | 手のひらサイズの白いフクロウ。首が180度回る。飛ぶのは下手(木から落ちてくる登場) |
| 正体(3年まで秘密) | 千年前の碑守ピュタゴラスの使い魔。ゼノンが理を消し始めたとき、記憶を封じられて東へ飛ばされた |
| 知っていること | 理の知識が「口をついて出る」。自分でも理由が分からず、そのたびに首をかしげる |
| 知らないこと | 自分の過去、主人の名、北の塔のこと。「北」と聞くと胸がざわつく |
| 性格 | 明るく、おせっかい。怖がりだが仲間の前では強がる。ユウを対等の相棒として扱う |
| 口調 | 一人称「ボク」。語尾「〜だよ」「〜なんだ」「〜かも」。驚くと「ホホッ!」。決めゼリフ「**まちがえたら、言い直せばいい**」 |
| 戦闘での役割 | ヒント(「ピタのささやき」)、回復(「羽根の風」) |
| 禁止 | 説教しない。答えを先に言わない(ヒントは最初の一手まで) |

### 2.3 テオ(村の商人)

| 項目 | 内容 |
|---|---|
| 年齢・立場 | 30代。村で唯一の店「テオ商店」を営む。道具屋・武具屋を兼ねる |
| 性格 | おおらか、声が大きい、計算が苦手なのに商人。損得にこだわるが根はお人よし |
| 口調 | 「〜だぜ」「〜だろ?」。口ぐせ「**損した!**」「**得した!**」 |
| 物語での役割 | 1年: 勘定が合わない事件でプロローグを開く。各章のあとに「損得」の小話をする(2年のゼノンの動機への伏線: 「数がなけりゃ損も得もねえのになあ」) |
| 店のセリフ | 買い物時「毎度! 得したろ?」/ 金が足りない「損はさせねえが、ツケもやらねえ」 |

### 2.4 村長

| 項目 | 内容 |
|---|---|
| 立場 | はじまりの村の長。70代。碑の伝承を語り継ぐ役 |
| 口調 | 穏やか。「〜ですな」「〜でしょう」。子どもにも敬語 |
| 役割 | 旅の動機づけ。章クリアごとに「碑の伝承」を一つ語る(世界観の小出し) |

### 2.5 レナ(2年の仲間、1年第7章に顔見せ)

| 項目 | 内容 |
|---|---|
| 立場 | 15歳。王国騎士団の見習い。兄ノアを探して単独でプリマまで来ている |
| 性格 | 生真面目、責任感が強い、少し不器用。ユウの「言い直す」力に最初は懐疑的 |
| 口調 | 「〜だ」「〜か?」。敬語は上官にだけ |
| 1年での役割 | 記録の塔で合流。ラスボス後に「王都へ来てほしい」と告げる |

### 2.6 ゼノン(黒幕。1年では名前のみ)

- 元王国大賢者。家族を戦争で失い、「争いは損得の勘定から生まれる。数を消せば争いが消える」と信じた
- 悪意はない。人々の幸福を願っている点は変わらない。**間違えた善人**
- 1年では「古文書の一文」と「歪みの使徒のセリフ」でだけ存在が示される

## 3. 文体・表記ルール(台本共通)

- 対象は中学1年生。**漢字は小学校修了程度+中1配当**、難しい語にはふりがなを付けない代わりに言い換える(「侵食」→「むしばむ」)
- 1行 = 40〜60字。1つの吹き出しに2文まで
- 数式は会話内でも正しい記法(「(−3)+(−4)」)。ただし会話文では読みやすさ優先で「マイナス3」も可
- 数学用語は教科書の言葉に合わせる(「絶対値」「項」「移項」「比例定数」)。造語で言い換えない
- 説教・「勉強しなさい」系のセリフは禁止。数学の意味づけは選択肢の「解説ルート」に置く
- 死・暴力・恐怖の直接描写はしない。魔物は「元の姿に戻る」
- 主人公のセリフは短く、一人称を使わない
- 選択肢は2〜3個。**間違い選択肢を選んでも罰しない**(ピタが言い直して、同じ報酬)

## 5. 学習イベントの設計原則

各章に 1〜2 個置く「戦闘ではない学習イベント」の作り方。

1. **体験 → 名前**: まず現象を見せ(橋が縮む)、次に選択肢で考えさせ、最後にピタが教科書の言葉で名づける(「これが絶対値」)
2. **選択肢は誤答も歓迎**: 誤答を選んだら、ピタが「そう思うよね。でも…」と言い直す。報酬は同じ
3. **1イベント 1概念**: 詰め込まない。絶対値の碑なら「0からの距離」だけ
4. **章のまとめ = 碑文の言い直し**: ボス後に、歪んだ碑文と正しい碑文を並べて選ばせる(3択)。これがその単元の「最重要の一文」になる
5. **所要 1〜2分**: 5分区切りのプレイに収まる長さ
