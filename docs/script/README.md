# 台本の書き方

台本は Markdown の「台本形式」で書き、実装時にスクリプトデータ(YAML)へ変換する(変換はスクリプトで自動化する)。人が読んでレビューするための形式なので、読みやすさを優先する。

## ファイル構成

```
docs/script/
  README.md            この文書
  g1/                  1年版
    00_prologue.md     プロローグ
    01_sign_forest.md  第1章 符号の森
    02_...             以降、章ごと
```

## シーンの書式

```
## C1-4 絶対値の碑            ← シーンID と 名前
- 種類: 学習イベント          ← 章冒頭 / ノード導入 / 学習イベント / ボス前 / ボス戦中 / ボス後 / 村 / 小ネタ / 敵セリフ
- 背景: forest_stone          ← 素材ID(assets.md と対応)
- 登場: ピタ、ユウ            ← 立ち絵を出す人物
- 発生: ノード abs_stone に入ったとき
- 所要: 約1分

ピタ「セリフ…」              ← 人物名「本文」。1つの吹き出し = 1行
ユウ「セリフ…」
※ 演出: 画面が揺れる         ← ※ で始まる行は演出・効果(会話には出ない)

▶ 選択肢                     ← 選択肢ブロック
  1. 「−5」 → C1-4a
  2. 「3」 → C1-4b

[C1-4a]                      ← ラベル(選択肢の飛び先)
ピタ「…」
→ C1-4z                      ← 無条件ジャンプ

[C1-4z]
ピタ「…」
※ 効果: アイテム入手 hint_feather ×1
```

## 記号

| 記号 | 意味 |
|---|---|
| `人物「…」` | セリフ。人物名は setting.md §2 の仮名 |
| `{player}` | 主人公名に置換 |
| `※ 演出:` | 画面効果(揺れ・フェード・SE) |
| `※ 効果:` | ゲーム内効果(アイテム・フラグ・回復・入力キー解放 ×/^/x/y/π/√/()) |
| `※ 表情:` | 立ち絵の差分(normal / happy / worried / surprised) |
| `▶ 選択肢` + `1.` `2.` | 選択肢。`→ ラベル` で飛び先 |
| `[ラベル]` | 飛び先の目印 |
| `→ ラベル` | 無条件ジャンプ |
| `(解説)` | 選択肢の末尾に付けると「解説ルート」(want F64)の印 |

## 敵セリフ表の書式

戦闘中のセリフは表で書く。列は 登場 / 被弾 / 回避(プレイヤー誤答) / 撃破。

## レビューの観点

1. 声が人物に合っているか(setting.md §2 の口調)
2. 中1が読める言葉か(§3 文体ルール)
3. 学習イベントが「体験 → 名前」の順になっているか(§5)
4. 1シーンの長さが 5分区切りを壊していないか
