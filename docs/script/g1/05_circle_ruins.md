# 第5章 円の遺跡 — 平面図形

- 対応: scenario.md §4.5(ノード先頭に「発掘隊のキャンプ(town)」を追加)
- ノード: 発掘隊のキャンプ(town) → 遺跡の門(battle) → 壁画の間(event) → 対称の回廊(battle) → おうぎ形の広場(battle) → [作図の祭壇(secret)] → 円環の番人(boss)
- 出題: `g1.geo.angle / symmetry / sector / construct` + ボス戦で 図形の移動・円と直線(選択式、SVG)
- 章の一文(碑文): **「おうぎ形の 弧の長さと 面積は、中心角に 比例する」**
- 所要: 約40分
- 章のテーマ: 形には きまりがある。動かしても、回しても、裏返しても 変わらないもの。そして「円」
- この章から 図形を SVG で見せる。台本中の「※ 図:」は SVG で描く指定

### フェーズ③の SVG 問題(例)

- 図形 A と B。「A を B に 重ねる 移動は?」(平行移動 / 回転移動 / 対称移動)
- 「点 O を 中心に 図形 A を 180° 回転移動した 図は?」(4つの図から選ぶ)
- 円 O と 接線 ℓ、接点 A。「∠OAℓ は?」(90° / 45° / 60° / 180°)
- 円 O の 弦 AB と 中心 O から 引いた 垂線。「垂線は 弦 AB を どう 分ける?」(2等分する / 3等分する / 分けない)

### プレイヤーが誤答したとき(汎用)

## レビュー用メモ

- **SVG が必要な問題**: 角度(交わる直線・三角形)、おうぎ形(中心角と半径を表示)、図形の移動(A/B/C/D の配置)、線対称・点対称(図形の提示)、円と接線・弦。テンプレート側に「図の指定(頂点座標・角度・ラベル)」を持たせ、描画は共通ヘルパで行う(要件 F48、TASKS T6-1)
- **π の入力**: パレットに「π」を追加(要件 F49 の一覧に追加)。`6π`、`9π` の形で判定。数値近似(18.84)は不正解
- 平行線と角(同位角・錯角)は 2年の範囲なので、1年版の `g1.geo.angle` では扱わない。対頂角・直線上の角・三角形の内角の和(小学校既習)まで
- 学習イベント「壁画の間」は 図形の移動(体験→名前)と 三平方の伏線(静かな場面)を 1つに まとめた。約2分。伏線シーンでは 報酬を出さず、余韻を残す
- 番人は「変わらないのがよい」= 歪み(ゼノン)の思想を 受け取ってしまった 存在。「輪を直す」= 元に戻す、で 一貫
- 「白いフクロウを連れた碑守」「3、4、5」「9+16」は 3年 第7章の 回収まで 答えを言わない。フラグ `mural_seen` `guardian_owl_hint` を 3年版で 参照
