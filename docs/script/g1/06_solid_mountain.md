## C6-9 ボス戦中 — 立体王ポリ
- 種類: ボス戦中
- 戦闘: 3フェーズ。ポリの 崩れた 面が フェーズごとに 戻る(演出)

| フェーズ | 出題 | 開始時のセリフ |
|---|---|---|
| ① | `g1.solid.prism` / `g1.solid.pyramid` ★2〜3(見取図 SVG つき) | 立体王ポリ「まず 余の 体の 体積を 述べよ。柱と 錐、区別できるか」 |
| ② | `g1.solid.surface` ★2〜3(見取図または展開図 SVG つき) | 立体王ポリ「次は 表面だ。見えぬ 面まで 数えられるか」 / ピタ「展開図を 思い浮かべて! 底面は 2つ!」 |
| ③ | 見取図・投影図(SVG)から 立体を 選び、体積を 求める(選択 → 数値) | 立体王ポリ「最後だ。余の 影を 見て、余の 形を 当てよ。そして 体積を 述べよ」 |

### フェーズ③の流れ(例)

1. 投影図(平面図: 円、立面図: 三角形)を示す →「この 立体は?」(円錐 / 円柱 / 三角錐 / 球)
2. 「底面の 半径 3、高さ 4 のとき、体積は?」→ 式入力(12π)
3. 別の投影図(平面図: 正方形、立面図: 長方形)→ 四角柱 → 体積(数値)

### プレイヤーが誤答したとき(汎用)
立体王ポリ「……余の 面は、まだ 足りぬ」

### 連続正解 3回
立体王ポリ「面が……戻ってくる。余の 体が、重さを 取り戻していく……」

### 撃破
※ 演出: ポリの 体の 多面体が すべて そろい、光る。王は 山頂の 一つの 大きな 正多面体の 岩(水晶のような)に 戻る。転がっていた 岩が 止まる
立体王ポリ「……見えぬ 面まで、数えられた。余は、余の 体積を 思い出した」
立体王ポリ「小さきものよ。碑を 直せ。余は また、山を 支えよう」

## レビュー用メモ

- **SVG が必要な問題**: 角柱・円柱・角錐・円錐・球の 見取図(寸法ラベルつき)、展開図、投影図(平面図・立面図)、直方体の 辺の 位置関係(辺を ハイライト)。3D は 描かず、教科書と同じ 2D の 見取図(斜め投影)で 十分
- **π を含む 式入力**: `12π`、`36π` などの 判定は 第5章と共通。`4/3π` の ような 分数×π も 受ける(`(4/3)π` `4π/3` `4/3π` を 同値扱い)
- 球の 公式の 語呂合わせ(「身の上に心配あるので参上」)は 定番だが、先生の 教え方と 合わなければ 差し替える
- 立体王は「見えないものは ないのと同じ」= 歪みの 別の 顔。番人(変わらないのがよい)、書記官(名前を消せば争わない)と 並べて、歪みが「きまりを 忘れさせる 言葉」だと 見せていく
- 第6章で 初めて 塔を 目視する(フラグ `tower_seen`)。第7章の 記録の塔は「北端の 古い塔」で、天空の塔とは 別物。混同しないように 第7章冒頭で ピタに 言わせる
- 「北から来た旅人」の「形が ない、溶けたみたい」は 3年の 塔周辺の 描写への 布石
