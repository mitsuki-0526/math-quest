# 第3章 未知の洞窟 — 方程式

- 対応: scenario.md §4.3(ノード先頭に「野営地(town)」を追加。店・宿・泉の拠点が必要なため)
- ノード: 野営地(town) → 洞窟の入口(battle) → 第一の天秤(event) → 移項の回廊(battle) → かっこの部屋(battle) → [分数の泉(secret)] → 比の橋(battle) → 未知なる影 X(boss)
- 出題: `g1.eq.basic / linear / paren / fraction / ratio / word`
- 章の一文(碑文): **「等式は 両辺に 同じことをしても 成り立つ」**
- 所要: 約40分
- 章のテーマ: 分からないものにも、正体(値)がある。両辺に同じことをして、少しずつ正体を追いつめる

## C3-3 第一の天秤
- 種類: 学習イベント
- 背景: cave_balance
- 登場: ピタ、ユウ
- 発生: ノード balance3 に入ったとき
- 所要: 約2分
- 概念: 等式の性質(両辺に同じことをしても釣り合いは変わらない)。移項は「両辺から同じ数を引く」ことの省略

### 設計

| 段階 | 内容 |
|---|---|
| 体験 | 部屋そのものが巨大な天秤。左の皿に「箱 1つ と おもり 3個」、右の皿に「おもり 8個」が乗って釣り合っている。「箱の重さを 知るには どうする?」を選ぶ |
| 名前 | ピタが「両辺から 同じだけ 取っても 釣り合う。これが 等式の性質」と名づける。式で書くと x+3=8 → x=8−3 → 「+3 が 右に 移って −3 になったように 見える。これを 移項という」 |
| 確認 | 「箱 2つ = おもり 10個。箱 1つは?」→ 「両辺を 2で 割る」を選ぶ |
| 報酬 | 時間延長の砂 ×2 |

### 台本

※ 演出: 部屋全体が天秤。左皿: 箱(?)+おもり3個、右皿: おもり8個。釣り合っている
ピタ「うわ、部屋が まるごと 天秤だ」
ピタ「左に 箱が 1つと、おもりが 3個。右に おもりが 8個。ぴったり 釣り合ってる」
ピタ「箱の中身は 見えない。……この箱の重さ、どうやったら 分かるかな?」

▶ 選択肢
  1. 「両方の皿から おもりを 3個ずつ 取る」 → C3-3a
  2. 「左の皿から おもりを 3個 取る」 → C3-3b
  3. 「右の皿に おもりを 3個 足す」 → C3-3c

[C3-3a]
※ 表情: ピタ happy
※ 演出: 両皿から3個ずつ消える。左: 箱、右: おもり5個。釣り合ったまま
ピタ「そう! 両方から 同じだけ 取れば、釣り合いは 崩れない。残ったのは 箱 1つ と おもり 5個」
ピタ「つまり 箱の重さは おもり 5個分だ」
→ C3-3z

[C3-3b]
※ 演出: 左から3個消え、天秤が右に傾く
ピタ「あっ、傾いた! 左だけ 軽くしたら、釣り合いが 崩れちゃう」
ピタ「同じことを 右にも しなきゃ。右からも 3個 取ると……釣り合った。箱 1つ と おもり 5個」
→ C3-3z

[C3-3c]
※ 演出: 右に3個増え、天秤が右に傾く
ピタ「傾いちゃった。右だけ 重くしたら だめだね」
ピタ「片方だけ 変えると 釣り合いが 崩れる。両方から 3個ずつ 取ってみよう。……ほら、箱 1つ と おもり 5個」
→ C3-3z

[C3-3z]
※ 演出: 箱が開き、中におもり5個
ピタ「当たり! 箱の重さは 5 だった」
ピタ「いまのを 式で 書くとね。箱を x として、x + 3 = 8」
※ 演出: 式が浮かぶ。「x + 3 = 8」→「x + 3 − 3 = 8 − 3」→「x = 5」
ピタ「両辺から 3 を 引いて、x = 8 − 3 = 5。両辺に 同じことをしても 等式は 成り立つ。これが 等式の性質」
ピタ「それでね、途中を 飛ばして 見ると『左の +3 が、右に −3 になって 移った』ように 見えるでしょ」
※ 演出: 「x + 3 = 8」→「x = 8 − 3」(+3 が右に移り −3 になるアニメ)
ピタ「これを 移項っていうんだ。符号を 変えて、反対側に 移す。……また 口が 勝手に!」
ピタ「じゃあ確認。今度は 箱が 2つ で、右が おもり 10個。箱 1つ の重さを 知るには?」

▶ 選択肢
  1. 「両方の皿を 半分にする(両辺を 2で 割る)」 → C3-3y
  2. 「左の箱を 1つ 取る」 → C3-3x
  3. 「両方から おもりを 2個ずつ 取る」 → C3-3w

[C3-3x]
ピタ「左だけ 変えたら 傾いちゃうよ。右も 同じように しないと」
ピタ「両方を 半分にしよう。箱 1つ と おもり 5個。2x = 10 の 両辺を 2で 割って x = 5」
→ C3-3y

[C3-3w]
ピタ「うーん、左には おもりが ないから 取れないよ。左は 箱だけ」
ピタ「両方を 半分にしてみて。箱 1つ と おもり 5個。2x = 10 の 両辺を 2で 割って x = 5」
→ C3-3y

[C3-3y]
※ 表情: ピタ happy
ピタ「ホホッ! 足しても 引いても かけても 割っても、両辺に 同じなら 大丈夫」
※ 演出: 天秤の台座から 小袋が出てくる
ピタ「砂時計の 砂だ。これ、戦いの中で 時間を 少し 延ばせるみたい。取っておこう」

## C3-9 ボス戦中 — 未知なる影 X
- 種類: ボス戦中
- 戦闘: 3フェーズ。影の形が フェーズごとに 少しずつ はっきりしていく(演出)

| フェーズ | 出題 | 開始時のセリフ |
|---|---|---|
| ① | `g1.eq.basic` / `g1.eq.linear` ★2〜3 | 未知なる影 X「余は 何者でも ない。x + 7 = 3? 答えなど あるものか」 |

### フェーズ③の流れ(例)

1. 文章「1個 x 円の りんごを 5個 買って 1000円 出したら、おつりは 250円 だった」→ 選択式で式を選ぶ(1000 − 5x = 250 / 5x − 1000 = 250 / 1000 + 5x = 250 / 5 + x = 250)
2. 「x を求めなさい」→ 数値入力(150)
3. 過不足の問題、速さの問題も同じ形式で 2〜3問

### プレイヤーが誤答したとき(汎用)
未知なる影 X「ふふ……余は まだ x のままだ」

### 連続正解 3回

### 撃破

## レビュー用メモ

- **scenario.md との差分**: ノード先頭に「野営地(town)」を追加した。以降の章も「拠点(town)→…」の形にそろえる(scenario.md §4 を後で更新)
- 学習イベント「第一の天秤」は 2分と少し長め。**等式の性質と移項を1イベントで扱う**が、「体験(両辺から取る)→名前(等式の性質)→省略形(移項)」の順にして、移項を"別の新しいルール"に見せないようにした。先生の教え方と合うか確認してほしい
- 「0 で 割るのだけは だめ」は C3-10c の誤答フィードバックでだけ触れる(深入りしない)
- 比例式の解き方は「a×d = b×c」で統一。教科書の扱い(比の値で解く方法)を優先するなら C3-7 と ヒントを差し替える
- X の正体を「黒猫」にしたのは、「正体が分かる=消える」ではなく「元に戻る」を見せるため(ピタの気づき → 3年のテーマへの布石)。以後 黒猫エックスは 野営地の常連キャラとして 小ネタに使える
- 「旅の騎士」は レナの先ぶれ。名前も顔も出さない
