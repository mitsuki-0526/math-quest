# 第2章 名もなき者の平原 — 文字と式

- 対応: scenario.md §4.2
- ノード: 集落(town) → 風車の丘(battle) → 羊の囲い(event) → 草原の道(battle) → [古い井戸(secret)] → 石垣(battle) → 仮面の書記官(boss)
- 出題: `g1.expr.subst / collect / distribute / model / pattern`
- 章の一文(碑文): **「文字は どんな数の 代わりにも なれる」**
- 所要: 約40分
- 章のテーマ: 「まだ分からない数」に名前をつける。名前(文字)があるから、数えられるし、計算できる

## C2-3 羊の囲い
- 種類: 学習イベント

- 登場: ピタ、ユウ
- 発生: ノード sheepfold に入ったとき
- 所要: 約1分30秒
- 概念: 同じ数のまとまりが いくつかあるとき、「文字 × 個数」で表せる(4x と 4+x の区別)

### 設計

| 段階 | 内容 |
|---|---|
| 体験 | 囲いが4つ。羊が動き回っていて 数えられないが、4つとも同じ数だけ入っているのは分かる。「1つの囲いに x 匹 として、全部で何匹?」を選ぶ |

| 確認 | 「1匹 500ゴールドの羊を x 匹 買うと?」(500x / 500+x / x500) |
| 報酬 | 回復薬 ×2 |

### プレイヤーが誤答したとき(汎用)

### 連続正解 3回

## レビュー用メモ

- この章から **式入力**(F44 段階2)が必要: `collect` / `distribute` の解答は `5x`、`3a−2` のような形。判定は同値比較(`−2+3a` も正解)
- 「文字式の表し方のきまり」(×を省く、数字を先に、1x は x)は C2-2 と C2-3 で 体験として触れる。テンプレート側は、きまりに反した入力(`x4`)は「惜しい: 書き方」として扱い、正解にはしないが 解説で 書き方を示す(要件 F47 の解説に含める)
- 表しヒツジ(`model`)は選択式。文章題の式を「書かせる」のは1年版では避ける(入力の負担が大きく、正誤判定も難しい)
- 書記官は「名前を消せば 争わない」= ゼノンの思想の 弱いコピー。**2年でゼノン本人が同じことを 別の言葉で言う**。テオが「オレも似たようなこと言ったな」と拾うことで、伏線を意識させすぎずに残す
- メイの名前が戻るのが 章の感情的な報酬。表示名の変更(「羊飼いの少女」→「メイ」)は 会話エンジンの効果として実装(要件 F61 に追加)
