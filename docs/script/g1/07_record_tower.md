# 第7章 記録の塔 — データの活用(1年版 最終章)

- 対応: scenario.md §4.7(ノード先頭に「塔守の宿(town)」を追加)
- ノード: 塔守の宿(town) → 塔の入口(event) → 記録の間(battle) → 度数の階段(battle) → 古文書の間(event) → 代表値の回廊(battle) → [確率の窓(secret)] → 歪みの使徒(boss) → エピローグ(event)
- 出題: `g1.data.mean / median / freq / prob` + ボス戦で 1〜6章の 総復習
- 章の一文(碑文): **「平均だけでは、散らばりは 分からない」**
- 所要: 約50分(エピローグ含む)
- 章のテーマ: たくさんの 数を、一つの 数で 語るな。散らばりを 見よ。そして「歪みには 送り主が いる」

### 設計

| 段階 | 内容 |
|---|---|
| 体験 | 二つの村(東の村・西の村)の 10年分の 収穫記録。平均は どちらも 100。「来年、種を 分けてもらうなら どっちの 村?」を 記録(ドットプロット/ヒストグラム SVG)を 見て 選ぶ |

| 伏線 | 騎士団の 記録(ノア、北へ)と、古文書(大賢者ゼノン、王都を去る) |

## レビュー用メモ

- **ラスボスの 総復習(フェーズ③)** は プレイヤーの `stats` から 苦手テンプレートを 優先して 出す(要件 F46)。苦手が ない 生徒には 各章から 均等に
- **レナの「かばう」** は 1年版では 演出のみ(1回)。2年版で 正式な 仲間スキルになる
- **歪みの使徒の 元の姿 = 木彫りの 人形**。ゼノンの 失った 家族(娘)の ものだが、1年版では 説明しない。2年 第4章で 回収
- **「終わりではない。主は それを『始まり』と 呼んで」** は ゼノンの 動機が 単純な 破壊ではないことの 布石
- **エピローグ E-2 の 七つの碑文** は、そのまま 1年生の「単元の まとめ」になる。成績画面や 復習の泉からも 見られるようにすると 学習面の 価値が 高い(want として TASKS に 追加候補)
- **クリア後**: ワールドマップは 全章 自由に 遊べる 復習モード。2年版が できるまでの つなぎ
- 塔の 記録の 数値(雨量 1200ミリ など)は 架空。地理的な 整合性は 求めない
- 学習イベント「古文書の間」は 約2分30秒と 最長。散らばりの 体験 → 範囲・ヒストグラムの 名づけ → 中央値の 確認 → 伏線 2つ、と 詰まっているので、実装時に 伏線 部分を 別ノードに 分けてもよい
