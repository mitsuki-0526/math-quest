# 第4章 水車の湖 — 比例と反比例

- 対応: scenario.md §4.4(章名を「天秤の湖」→「水車の湖」に変更。第3章で天秤を使い切ったため。scenario.md は後で更新)
- ノード: 湖畔の町(town) → 水位計の桟橋(battle) → 座標の浮島(event) → 水車小屋(battle) → [霧の沖(secret)] → 竜の岬(battle) → 湖の双子竜(boss)
- 出題: `g1.func.prop / invprop / coord / graph`

- 章のテーマ: ともなって変わる二つの量。「増えれば増える」も「増えれば減る」も、どちらも きまり

## C4-8 ボス戦中 — 湖の双子竜
- 種類: ボス戦中
- 戦闘: 3フェーズ。二匹が 交互に 問いを出す

| フェーズ | 出題 | 開始時のセリフ |
|---|---|---|
| ① | `g1.func.prop` ★2〜3(式から値、値から式) | ナラビ「まずは 我からだ。y = 4x で x = 7 のとき、y は? 増えれば 増える!」 |
| ② | `g1.func.invprop` ★2〜3 | サカサ「次は 我だ。y = 24/x で x = 6 のとき? 増えれば 減る!」 / ピタ「切りかえて! 今度は かけて 同じ数になる ほうだよ」 |
| ③ | グラフ読み取り(SVG: 座標平面に 比例・反比例のグラフ)。「この グラフの 式は?」(選択式)「x = 6 のとき y は?」(数値) | ナラビ・サカサ「「ならば 二人 いっしょに! この 線を 読んでみよ!」」 |

### フェーズ③の SVG 問題(例)

- 原点を通る直線が (2, 6) を通っている → 「式は?」(y=3x / y=2x / y=6/x / y=x+4)
- 双曲線が (2, 6) を通っている → 「式は?」(y=12/x / y=3x / y=6/x / y=2x)
- 上のグラフで「x = 4 のときの y は?」(数値)
- 「点 (−2, 6) は どちらの グラフの上に あるか?」(選択)

### プレイヤーが誤答したとき(汎用)
ナラビ「ほら、増えれば 増えるのだ!」/ サカサ「ほら、増えれば 減るのだ!」(交互)

### 連続正解 3回
ナラビ「……我の 問いにも」
サカサ「……我の 問いにも 答えている、だと?」

### 撃破
※ 演出: 二匹の竜が 光に包まれ、小さくなって 二匹の 青と緑の トカゲになる。仲良く 碑の上に 並ぶ

- 学習イベント「座標の浮島」は 座標平面の見た目を SVG の座標問題と同じにしておく(ボス戦③の 読み取り問題への 予行演習になる)
