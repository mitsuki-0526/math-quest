# 第1章 符号の森 — 正の数と負の数

- 対応: scenario.md §4.1
- ノード: 村(town) → 森の小道(battle) → 符号の湿地(battle) → [隠し洞窟(secret)] → 絶対値の碑(event) → 乗除の谷(battle) → 累乗の崖(battle) → 符号王ネガ(boss)
- 出題: `g1.sign.addsub / muldiv / abs / mixed / primefactor`
- 章の一文(碑文): **「負の数どうしの積は 正である」**
- 所要: 約40分(会話をスキップしなければ)

## C1-4 絶対値の碑
- 種類: 学習イベント
- 背景: forest_stone
- 登場: ピタ、ユウ
- 発生: ノード abs_stone に入ったとき
- 所要: 約1分30秒
- 概念: 絶対値 = 0 からの距離(1概念のみ)

### 設計

| 段階 | 内容 |
|---|---|
| 体験 | 地面に数直線が刻まれ、−5 と 3 の位置に石像が立っている。「0 から遠いのは どっち?」を選ぶ |
| 名前 | ピタが「0 からの距離を 絶対値という」と名づける。「−5 の絶対値は 5」 |
| 確認 | もう1問、選択式で「−7 の絶対値は?」(7 / −7 / 0) |
| 報酬 | ヒントの羽根 ×2。誤答しても同じ |

### 台本

※ 演出: 地面に大きな数直線。0 の位置に小さな石碑、−5 と 3 の位置に石像
ピタ「小さな碑だ。道しるべかな。地面に 数の目盛りが刻んである」
ピタ「石像が 2つ。こっちが −5、あっちが 3 の位置に立ってる」
※ 演出: 碑文のアップ「0 より いかに遠きかを 見よ」
ピタ「『0 より いかに遠きかを 見よ』…。ねえ {player}、0 から遠いのは どっちの石像?」

▶ 選択肢
  1. 「−5 の石像」 → C1-4a
  2. 「3 の石像」 → C1-4b
  3. 「同じ」 → C1-4c

[C1-4a]
※ 表情: ピタ happy
ピタ「そう! −5 は 0 から 5 はなれてる。3 は 3 だけ。マイナスがついてても、遠さは 5 なんだ」
→ C1-4z

[C1-4b]
ピタ「そう思うよね、3 のほうが『大きい』から。でも 聞かれてるのは『遠さ』なんだ」
ピタ「−5 は 0 から 左に 5 歩。3 は 右に 3 歩。遠いのは −5 のほうだよ」
→ C1-4z

[C1-4c]
ピタ「うーん、おしい。左に 5 歩 と 右に 3 歩。歩いた数が ちがうよね」
ピタ「マイナスがついてても、遠さは 5。0 から遠いのは −5 のほうなんだ」
→ C1-4z

[C1-4z]
※ 演出: 石像 −5 が光る
ピタ「この『0 からの距離』のことを、絶対値っていうんだ。−5 の絶対値は 5。3 の絶対値は 3」
ピタ「……また 口が勝手に。まあ、合ってると思う」
ピタ「じゃあ確認。−7 の絶対値は?」

▶ 選択肢
  1. 「7」 → C1-4y
  2. 「−7」 → C1-4x
  3. 「0」 → C1-4x

[C1-4x]
ピタ「距離に マイナスは つかないよ。0 から 7 歩 はなれてるから、絶対値は 7」
→ C1-4y

[C1-4y]
※ 表情: ピタ happy
ピタ「ホホッ! これで 道しるべが 正しく読める」
※ 演出: 碑が光り、羽根が2枚 舞い落ちる
ピタ「あれ、ボクの羽根…? いや、ボクのじゃない。でも、なんだか 使えそう」
※ 効果: アイテム入手 hint_feather ×2
ピタ「これを使うと、戦いの中で ボクが もう一回 ささやけるみたい。取っておいて」

## レビュー用メモ

- 第1章は「符号」に集中。素因数分解は教科書の1章末に入るが、寄り道(隠し洞窟)に置いた。**寄り道を want にする場合は 累乗の崖の戦闘に素数バチを混ぜる**
- 学習イベントは2つ(絶対値の碑・碑文の言い直し)。どちらも誤答で罰なし
- 「(−2)² と −2²」は C1-6 でピタが口頭で触れるだけ。テンプレート `g1.sign.mixed` ★3 で出題する
- ネガは「悪」ではなく「思いこまされている」。倒すと石に戻る。2年以降のボスも同じ構図で書く
- テオの「数がなけりゃ損も得もねえ」は ゼノンの動機(2年)への伏線。1年中は 章ごとに1回、軽く繰り返す
