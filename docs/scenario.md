## 0. この文書の役割

- 3学年を通した世界観・物語の骨格を固定する(ここがぶれると続編が書けない)
- **1年版は章ごとの詳細**(舞台・あらすじ・ノード構成・敵=問題タイプ・ボス・イベントの学習的意味)まで書く
- 2年版・3年版は章ごとのあらすじと伏線の回収先まで書き、詳細は続編制作時に埋める

## 1. 世界観

### 1.1 世界「ロジカ大陸」

世界は「**理(ことわり)**」によって形を保っている。理とは数・形・関係のきまりのことで、人々は意識せずにその上で暮らしている(橋の長さは測ったとおり、商人の勘定は合う、種をまけば比例して実る)。

各地には古代の学者たちが理を刻んだ「**理の碑(ことわりのひ)**」が立っており、碑が健全なあいだ、その土地の理は守られる。

### 1.2 災厄「歪み(ゆがみ)」

物語の始まる少し前から、大陸に「歪み」が広がり始めた。歪みに飲まれた土地では **数が嘘をつく**。

- 橋の看板が「長さ −12m」になり、渡ろうとすると橋が縮む
- 商人の勘定が合わず、町中で喧嘩が起きる
- 井戸の水が「比例」を忘れ、汲んでも汲んでも増えない

歪みは理の碑を侵食し、碑の刻文を書き換える。碑を修復する(=その単元の問題を解いて理を「言い直す」)と土地は元に戻る。歪みから生まれた魔物は、それぞれ **特定の理の誤り** の姿をしている(「マイナス×マイナスをマイナスにしてしまう」魔物、「文字を数に代入できない」魔物…)。

### 1.3 三つの国(=三学年)

| 学年 | 国・舞台 | テーマ | 物語上の役割 |
|---|---|---|---|
| 1年 | **はじまりの国 プリマ**(東の辺境: 村・森・湖・遺跡・山・塔) | 数の秩序を取り戻す | 旅立ち。歪みは「誰かが起こしている」と知る |
| 2年 | **王国 セクンダ**(大陸中央: 王都・城下・街道) | 変化と関係を読み解く | 黒幕と動機が判明。仲間が増える |
| 3年 | **天空の塔 テルティア**(北端の塔: 登るほど理の根源に近づく) | 根源と形にたどり着く | 最終決戦と和解。主人公が新しい理の書を書く |

### 1.4 トーン

- 王道ファンタジー。明るく、少しユーモアあり(敵の名前・村人の小ネタ)。怖い描写・死の描写はしない
- 「数学ができないと進めない」ではなく「数学が分かると世界が直る」の気持ちよさを軸にする
- 説教はしない。数学の意味づけは仲間のセリフの選択肢(解説ルート)に置き、読み飛ばせる

## 3. 全体構成

### 3.1 三部作としての流れ

```
1年 プリマ    : 村を出る → 7つの碑を直す → 歪みに送り主がいると知る → 王国からの使者(レナ)と出会う
2年 セクンダ  : 王都へ → レナと組む → 黒幕ゼノンと動機を知る → 王都を守る → 北の塔の存在を知る
3年 テルティア: 塔を登る → ノアと再会 → ピタの正体 → 最上階でゼノンと対峙 → 和解 → 新しい理の書
```

### 3.2 各学年を単体で始められる仕組み

- 各学年版の冒頭に「**これまでのあらすじ**」(スキップ可、1分)を置く
- 前学年のセーブがあれば: レベル・称号・図鑑を引き継ぎ、ピタ/レナとの会話に「前作を知っている」差分セリフが入る
- なければ: その学年の標準レベル(2年 Lv10、3年 Lv20 相当)で開始し、仲間は最初から同行している
- 物語上の必須情報は、その学年の中で必ずもう一度語られる(前作を遊んでいなくても理解できる)

### 3.4 ゲームシステムと物語の対応(3学年共通ルール)

## 4. 1年版「はじまりの国 プリマ」詳細

単元順は東京書籍『新しい数学1』に従う。1章 = 7〜9ノード、プレイ時間の目安は 1章 35〜50分(1ノード約5分)。

### 4.0 プロローグ(ノード: はじまりの村)

- ユウの名前入力
- 村の朝。テオの店で勘定が合わない騒ぎ(「3個買ったのに、おつりが増えた!」)
- 村はずれの橋の看板が「長さ −12m」になっている。渡れない
- 木の上から落ちてきたフクロウ(ピタ)と出会う。ピタは自分の名前しか覚えていないが、看板を見て「これは歪みだ。理の碑が侵されている」と言う
- 村長: 「森の奥の碑を見てきてくれないか」→ 第1章へ
- **チュートリアル戦闘**(森の入口でマイナススライム1体、制限時間なし、ヒント無料)

### 4.1 第1章 符号の森(正の数と負の数)

| 項目 | 内容 |
|---|---|
| 舞台 | 村の東の森。奥へ行くほど「向き」がおかしくなる(川が逆流、木が下に伸びる) |
| あらすじ | 森の碑は「符号」を司る。碑が侵され、森では「反対」が反対でなくなっている。碑を守る**符号王ネガ**は「マイナスはいつだってマイナスだ!」と信じ込まされている。碑を直すと橋の看板も直り、村人が渡れるようになる |
| ノード構成 | 村 → 森の小道(戦闘) → 符号の湿地(戦闘) → [寄り道: 隠し洞窟(素因数分解)] → 絶対値の碑(イベント) → 乗除の谷(戦闘) → 累乗の崖(戦闘) → BOSS 符号王ネガ |
| 雑魚敵 = 問題タイプ | **マイナススライム**: 正負の加減(2〜3項) / **プラマイコウモリ**: 正負の乗除 / **ゼッタイチ・ゴーレム**: 絶対値・数の大小 / **クロスバッタ**: 四則混合(かっこ・累乗含む) / **素数バチ**(寄り道): 素因数分解 |
| ボス | **符号王ネガ**(3フェーズ): ①加減 ②乗除(負の数の個数と符号) ③数直線の読み取り(SVG: 点の位置を答える)+四則混合 |
| イベントの学習的意味 | 「絶対値の碑」: 碑文「0からの距離」。選択肢で「−5と3、0から遠いのは?」を体験。ボス後: ネガ「マイナスとマイナスをかけると…戻るのか」 |
| 伏線 | テオ「歪みのせいで損したよ。数なんてなければ損も得もないのになあ」 / 碑文の末尾「北を見よ」 |

### 4.2 第2章 名もなき者の平原(文字と式)

| 項目 | 内容 |
|---|---|
| 舞台 | 森を抜けた草原。風車小屋と羊飼いの集落 |
| あらすじ | 平原では人も物も「名前」を失いかけている。羊飼いは羊が何匹いるか言えない(「えーと、あの数だよ、あの…」)。文字を使えば「まだ分からない数」にも名前をつけられる、とピタが思い出す。碑を守る**仮面の書記官**は、名前を全部消してしまった張本人 |
| ノード構成 | 集落 → 風車の丘(戦闘) → 羊の囲い(イベント: 数量を文字で表す) → 草原の道(戦闘) → [寄り道: 古い井戸(規則性・n番目)] → 石垣(戦闘) → BOSS 仮面の書記官 |
| 雑魚敵 = 問題タイプ | **文字の妖精エックス**: 式の値(代入) / **まとめ屋ゴブリン**: 同類項をまとめる(式入力) / **分配キツネ**: 分配法則・かっこをはずす(式入力) / **表しヒツジ**: 数量を文字式で表す(選択式) / **規則ムカデ**(寄り道): n番目の数 |
| ボス | **仮面の書記官**(3フェーズ): ①代入 ②式の計算(式入力) ③文章から文字式を立てる(選択式)+「a=3のときの値」 |
| イベントの学習的意味 | 羊の囲い: 「1つの囲いにx匹、囲いが4つ」→ 4x。選択肢で「4+x」との違いを体験 |
| 伏線 | 書記官の仮面の裏に王国の紋章(2年で王国の話につながる) |

### 4.3 第3章 未知の洞窟(方程式)

| 項目 | 内容 |
|---|---|
| 舞台 | 平原の先の山すそにある洞窟。中は天秤の形をした部屋が続く |
| あらすじ | 洞窟の奥には「未知なる影 X」が住み、村から持ち去られた道具を隠している。影は正体を隠すが、天秤の部屋を通るたびに正体(値)が絞り込まれていく。等式の性質=天秤の両側に同じことをしても釣り合いは変わらない |
| ノード構成 | 洞窟の入口(戦闘) → 第一の天秤(イベント: 等式の性質) → 移項の回廊(戦闘) → かっこの部屋(戦闘) → [寄り道: 分数の泉(分数係数)] → 比の橋(戦闘: 比例式) → BOSS 未知なる影 X |
| 雑魚敵 = 問題タイプ | **てんびんスライム**: x+a=b, ax=b / **移項ネズミ**: ax+b=c, 両辺にx / **かっこトロル**: かっこを含む方程式 / **分数ゴースト**(寄り道): 分数・小数係数 / **比のカニ**: 比例式 a:b=c:x |
| ボス | **未知なる影 X**(3フェーズ): ①基本の方程式 ②複雑な方程式 ③文章題(選択式で式を立てる → 数値で解を答える) |
| イベントの学習的意味 | 第一の天秤: 両側から同じおもりを取る操作を選択肢で行い、「移項」の意味を体験 |
| 伏線 | Xの正体は「値が決まると消える影」。ピタ「歪みも、正体が分かれば消えるのかもしれない」 |

### 4.4 第4章 天秤の湖(比例と反比例)

| 項目 | 内容 |
|---|---|
| 舞台 | 山を越えた先の大きな湖と湖畔の町。水位が歪んでいる |
| あらすじ | 湖の水位は雨の量に比例していたのに、比例を忘れて暴れている。湖畔の町は水車(反比例: 歯車の数と回転数)で暮らしている。碑を守るのは**湖の双子竜**(比例の竜と反比例の竜) |
| ノード構成 | 湖畔の町 → 水位計の桟橋(戦闘) → 座標の浮島(イベント: 座標) → 水車小屋(戦闘) → [寄り道: 霧の沖(グラフから式)] → 竜の岬(戦闘) → BOSS 湖の双子竜 |
| 雑魚敵 = 問題タイプ | **比例のヌシ**: y=ax の a・x・y を求める / **反比例のカニ**: y=a/x の a・x・y / **座標クラゲ**: 点の座標(選択式/複数値) / **グラフウナギ**(寄り道): グラフから式(選択式) |
| ボス | **湖の双子竜**(3フェーズ): ①比例 ②反比例 ③グラフ読み取り(SVG座標平面: 「このグラフの式は?」「x=6のときyは?」) |
| イベントの学習的意味 | 座標の浮島: 浮島の位置を (x, y) で言い当てる |
| 伏線 | 竜「北の塔から冷たい風が吹いてから、水が狂った」 |

### 4.5 第5章 円の遺跡(平面図形)

| 項目 | 内容 |
|---|---|
| 舞台 | 湖の北の古代遺跡。円形の広場と回廊 |
| あらすじ | 遺跡は古代の学者たちが理を刻んだ場所。歪みで角度と長さが狂い、扉が開かない。壁画に「直角三角形と3つの正方形」が描かれており、ピタは理由もなく涙を流す(3年の伏線)。碑を守る**円環の番人** |
| ノード構成 | 遺跡の門(戦闘) → 壁画の間(イベント: 伏線) → 対称の回廊(戦闘) → おうぎ形の広場(戦闘) → [寄り道: 作図の祭壇(垂直二等分線・角の二等分線の性質を選択式)] → BOSS 円環の番人 |
| 雑魚敵 = 問題タイプ | **角度ガーゴイル**: 角の計算(対頂角・直線上の角) / **対称ミラー**: 線対称・点対称の性質(選択式) / **おうぎ形の門番**: 弧の長さ・面積(π を含む式入力、または数値) / **作図ゴースト**(寄り道): 基本の作図で描ける線の性質(選択式) |
| ボス | **円環の番人**(3フェーズ): ①角度(SVG図) ②おうぎ形の弧と面積 ③円と直線・図形の移動(SVG、選択式) |
| イベントの学習的意味 | 壁画の間: 図形の名前を当てる短いクイズ。「なぜ正方形が3つ?」は答えを出さず、3年への宿題として残す |
| 伏線 | 壁画(→3年 三平方) / 番人「この遺跡を建てた学者のひとりは、フクロウを連れていた」(→ピタの正体) |

### 4.6 第6章 立体の山(空間図形)

| 項目 | 内容 |
|---|---|
| 舞台 | 遺跡の背後にそびえる山。岩が角柱・円錐・球の形をしている |

## 5. 2年版「王国 セクンダ」概要

単元順は東京書籍『新しい数学2』。詳細設計は2年版制作時に行う。

| 章 | 単元 | 舞台(仮名) | あらすじの要点 | ボス(仮名) |
|---|---|---|---|---|
| 序 | — | 王都への街道 | レナと旅立つ。「これまでのあらすじ」。王都で歪みが広がり始めている | — |
| 1 | 式の計算 | 錬金術師の工房街 | 工房の配合表(多項式)が歪んでいる。単項式・多項式の計算、等式の変形。文字式で「説明する」ことを学ぶ(偶数+奇数=奇数 を選択式で) | 錬金術師ギルドの長 |
| 2 | 連立方程式 | 双子の門 | 王城の門は2人の門番が2つの条件を出す。1人では開かない=2つの式で2つの未知数。レナとの共闘が本格化 | 双子の門番 |
| 3 | 一次関数 | 時計塔 | 時計塔の針が「歪み」で逆に進み、王都の時間がずれる。変化の割合・傾き・切片。グラフで未来を予測する | 時計守 |
| 4 | 図形の性質と合同(平行と合同) | 鏡の回廊 | 王城の地下。平行線と角、多角形の角、合同条件を選択式で。**ここでゼノンの姿と動機が語られる**(鏡に映る過去の映像) | 鏡の騎士 |
| 5 | 三角形と四角形 | 城壁 | 城壁の補修。二等辺三角形・平行四辺形の性質(選択式)と角度・長さの計算 | 城壁の巨人 |
| 6 | 確率 | 道化師のカジノ | 城下のカジノで道化師が「偶然」を歪めて人々を困らせる。樹形図・確率の計算。「起こりやすさ」を数で言う | 確率の道化師 |

ゼノンの動機(第4章で語られる): 若い頃、隣国との戦争で家族を失った。戦争の原因は領土と収穫の「計算」だった。「数がなければ人は損得を計算せず、争わない」と信じ、理を世界から消す研究を始めた。王国を追われ、北の塔にこもった。

## 6. 3年版「天空の塔 テルティア」概要

単元順は東京書籍『新しい数学3』。塔を1章1階層ずつ登る構成。
